# Challenge card

Audience: An independent reviewer or a targeted revision reviewer.

This is an optional view of the same project records, not a new source of truth or a mandatory output. Render only fields useful to the current request; preserve uncertainty and decisive evidence. Use the [shared contract](../contracts/research-contract.md) and [record API](../../docs/record-api.md).

## Basis
Exact Q/H/T and relevant material/assessment references; date of view.

## Review mode and subject
State independent/revision/adjudication, exact Q/H/T references, and the question to decide.

## Claims and strongest alternative
List the load-bearing claim IDs and the rival explanation or naive baseline.

## Evidence packet
Include original sources, code/configuration, complete counterexamples, and unknowns.
Retain inconvenient evidence from weak-scored, parked, killed, and older candidates if applicable.
Hide prior aggregate scores and model identity for an independent first review, not facts.

## Findings
For each claim: judgment, material refs, rationale, and exact scope.
An inaccessible source remains unverified; a vote is not material evidence.

## Resolution request
State the exact missing observation, proposed repair, or disputed validity condition.
If this is revision review, include the old finding and delta without calling it blind.

## View boundary
Pure wording or translation changes stay in this view. Scientific changes return to the owning skill and appropriate version; never repair a missing method invisibly in prose.
