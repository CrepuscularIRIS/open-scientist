# Direction card

Audience: A researcher choosing what to investigate.

This is an optional view of the same project records, not a new source of truth or a mandatory output. Render only fields useful to the current request; preserve uncertainty and decisive evidence. Use the [shared contract](../contracts/research-contract.md) and [record API](../../docs/record-api.md).

## Basis
Exact Q/H/T and relevant material/assessment references; date of view.

## Question and value
State the observed problem and whose decision would change if it were solved.
Label the best-case conclusion as conditional before results exist.

## What is already known
Link the relevant material and claim findings, including the strongest contrary finding.
Separate checked sources, interpretation, and unresolved factual questions.

## Proposed direction
State the mechanism in plain language and the strongest plausible alternative.
Give the candidate H version; do not create a new mechanism through this summary.

## Most dangerous assumption
Name the assumption, why the proposal depends on it, and a discriminating next observation.

## Investment choice
Pursue/refine/park/kill with reason, bounded next action, and any revisit condition.
Resources that are not known remain unknown; an estimate is labeled as such.

## View boundary
Pure wording or translation changes stay in this view. Scientific changes return to the owning skill and appropriate version; never repair a missing method invisibly in prose.
