# Operator: out_of_box

Generate a genuinely different hypothesis using existing ones only as analogy.
This is the operator for when the whole session has converged on one framing
and further variants do not produce a new discriminating prediction.

## When it applies

- Relevant hypotheses share the same assumption, established by inspecting their mechanisms.
- Reviews keep finding the same weakness across unrelated hypotheses, which
  usually means the framing is the problem.
- The user asks for something the field has not tried.

Use it sparingly. Most sessions need better versions of good ideas, not
stranger ideas.

## Procedure

1. Name the assumption every current hypothesis shares. Write it as a single
   sentence. This is the hard step; do it explicitly rather than in your head.
2. Ask what the phenomenon would look like if that assumption were false.
3. Look for an analogy in an adjacent field where the same pattern is explained
   differently: a different level of organisation, a different causal
   direction, a physical rather than biochemical explanation, a population
   effect rather than a molecular one.
4. Build the new mechanism from that analogy with specific entities and steps.
   Analogy is the source of the idea, not a substitute for the mechanism.
5. State what it predicts that no current hypothesis predicts. If there is no
   such prediction, it is not out of the box, it is a restatement.

## Failure mode

Novelty theatre. Unusual vocabulary, exotic entities, no mechanism, no
prediction. It reads as creative and reviews as empty, and unusual terminology can conceal that it is scientifically empty.

The guard is step 5. A hypothesis that predicts nothing new is not new.

The second failure mode is direct replication of the analogy's source field.
The analogy supplies the shape of the explanation, not the entities.

## Active bridge: structural obligations, not novel vocabulary

Start from the failed candidates' structural requirement: what signal, capability or contrast would any successful alternative need? List its available sources and excluded sources, preserving reasons such as information limits, cost, or an already occupied contribution.

The cross-domain mapping must align operations and their prerequisites. Map source object to target object, state to state, operation to operation, and invariant or conservation condition to its target analogue. Mark each supported mapping and each unresolved mismatch.

A shared name such as memory, energy, attention or evolution is a retrieval clue, not an established mechanism. Inspect the source method and target code or setting to determine whether the same relation can actually be enacted.

The analogy supplies structure, not an entitlement to import its entities, resources or guarantees. If the source uses privileged observations unavailable in the target, either construct a justified replacement or mark the transfer as presently invalid.

Preserve actual adverse evidence from the old framing. Do not declare it irrelevant solely because the child uses another vocabulary. Explain which premise changed and which original obstacle remains.

## Minimal input and output

Inputs include representative parent candidates, their common assumption, raw failures or observations, project constraints and available domain leads. Read evidence from diverse or parked candidates when it bears on that assumption; do not restrict context to high-scoring parents.

Output a proposed H or Q pivot with explicit parent/inspiration references, changed assumption, source-to-target mapping, concrete operations, structural requirement coverage, and a prediction unlike the current explanations. Cite the source actually inspected; an unverified analogy remains a lead.

If Q changes, update the project question and make the new candidate's relation explicit. Do not present a different scientific question as merely a better solution to the old one.

## Local recheck and stopping

Send source identity or mechanism uncertainty to research-retrieve; operational gaps to research-construct or research-code; unique predictions to research-test. Ask research-review to examine the changed premise and surviving evidence.

Stop when a specific alternative is ready for its next cheap check, or when no structural mapping/prediction exists. Polishing a noun-level analogy into a professional-looking card does not resolve that missing bridge.
