# Variant: empirical reveal

An empirical finding that changes what the field believes (a surprising direction or regime split).

This variant changes how the protocols in [protocols.md](../protocols.md) apply to this task type. It never switches one off. Seeds below are starting vocabulary; the study's `rubric` and `test_protocol` assets are rebuilt from this field's evidence (see [design](../../docs/design.md) §2–3).

| Protocol | How it applies |
|---|---|
| Falsification (3) | The predicted regime split or direction, stated before the run, with the rival "the effect is an artifact of X" predicting a different split. Numeric bars only if derived or measured elsewhere (RS hook shape (a)). |
| Review | Timing and competition (who else can see this soon), whether the "surprise" is already known under another name (alias channel), robustness across seeds and settings. |
| Deliverable | A plan or verified execution of the decisive measurement. |

Seeds: RS hook shapes, Companion timing. Watch for: a reveal that disappears under a fair baseline.
